# Mouse on Phone downloads

Download Mouse on Phone from the [latest release](releases/latest). The file is `Mouse-on-Phone.zip`.
To check the download, compare its SHA-256 checksum with the one on the release page.

This repository also publishes the Mouse on Phone website (download, support and privacy pages) with
GitHub Pages. The iPhone app is distributed through the App Store.

Questions and bug reports: open an issue in this repository.
