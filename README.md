# PhonePad downloads

Download PhonePad for Mac from the [latest release](releases/latest). The file is `PhonePad-Mac.zip`.
To check the download, compare its SHA-256 checksum with the one on the release page.

This repository also publishes the PhonePad website (download, support and privacy pages) with
GitHub Pages. The iPhone app is distributed through the App Store.

Questions and bug reports: open an issue in this repository.
